# Echoes of Them — Official Support & Documentation Website

This repository contains the source code for the official support, privacy policy, terms of service, product roadmap, changelog, and documentation website for the **Echoes of Them (Hilos / Archivo Oral)** multiplatform application.

## Repository Details

- **Host:** GitHub Pages (`https://support-evanescentecho.github.io/echoes-of-them-web/`)
- **Tech Stack:** Vanilla HTML5, Vanilla CSS3 (Tape Amber & Obsidian styling), Vanilla JavaScript (asynchronous JSON localization).
- **Structure:**
  - `index.html` — The main structural page.
  - `assets/` — Graphics assets (cassette logo, SVG vectors).
  - `css/` — Custom typography and stylesheet bindings (`styles.css`).
  - `js/` — Asynchronous theme switcher, language loader, and changelog timeline renderer (`script.js`).
  - `locales/` — Standalone JSON translation dictionaries for all 10 supported languages (EN, ES, DE, FR, IT, JA, KO, PT, RU, ZH).
